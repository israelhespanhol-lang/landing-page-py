# Instruções do Projeto

- **Atualização Automática no Git:**
  - Sempre que realizar ou finalizar qualquer alteração em arquivos ou novas funcionalidades solicitadas pelo usuário, faça automaticamente o commit das mudanças no Git (`git add .` e `git commit -m "..."`) com mensagens claras e descritivas em português.
  - Tente sincronizar com o repositório remoto ou instrua o push caso haja pendência de credencial interativa.
